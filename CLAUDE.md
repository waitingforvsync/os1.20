# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

BBC Micro OS 1.20 (MOS) disassembly as 6502 assembly source for the BeebAsm assembler. The single source file `os120.asm` must assemble to a byte-identical copy of the original 16KB ROM ($C000-$FFFF). Reference ROM MD5: `0a59a5ba15fe8557b5f7fee32bbd393a`.

## Build and Verify

```bash
# Assemble
beebasm -i os120.asm -o OS120.rom

# Verify byte-identical output
md5sum OS120.rom    # must be 0a59a5ba15fe8557b5f7fee32bbd393a

# Verbose assembly (shows addresses and generated bytes)
beebasm -i os120.asm -o OS120.rom -v
```

## Source Structure

`os120.asm` is a single ~21K-line file organized into chapters by subsystem, covering $C000-$FFFF:

- Constants and memory address definitions (top of file, before ORG)
- `ORG &C000` — character definitions, VDU tables, VDU/OSWORD routines, MODE changes, graphics, PLOT, cursor editing, resets, interrupts, CLI, buffers, star commands, OSBYTE/OSWORD, sound, tape/serial filing, keyboard, vectors, entry points
- `ORG &FFFA` — 6502 hardware vectors (NMI, RESET, IRQ)
- `SAVE` directive at end

## BeebAsm Syntax Notes

- Labels defined with `.labelName` at column 0; referenced as `labelName` (no dot)
- Constants defined as `name = value` (no dot prefix, unlike ACME's `.name = value`)
- Data: `EQUB`, `EQUW`, `EQUS` (not `!byte`, `!word`, `!text`)
- Hex prefix: `&` (not `$`)
- Lo/hi byte: `LO(expr)`, `HI(expr)`
- Accumulator mode must be explicit: `LSR A` not `LSR`
- Bitwise XOR operator: `EOR` (not `XOR`)
- No anonymous labels; converted to `._anonXXX` named labels
- No native big-endian word; use `EQUB HI(expr), LO(expr)`
- BeebAsm evaluates variable assignments immediately — no forward references in constants

## Conversion Origin

The source was mechanically converted from Toby Nelson's ACME-format disassembly (`os120_acme.a`) using `convert.py`. Both files are in `.gitignore` as they are not part of the deliverable. The BeebAsm source (`os120.asm`) is the canonical version going forward.
